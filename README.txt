PORTFOLIO SITE

1. Upload all files and the assets folder to your GitHub Pages repository.
2. Keep index.html at the repository root.
3. In GitHub: Settings > Pages > Deploy from a branch > main > /(root).
4. Update LinkedIn and email placeholders in index.html.
5. Add future certificates to assets, then duplicate the certification card in index.html.
6. Add future project cards by duplicating a project-card article in projects.html.
